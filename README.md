# Filtragem de Ocorrências de acidentes aérios em Joinville com Python

Este projeto em Python realiza a leitura de um arquivo CSV contendo registros de ocorrências de acidentes aérios e filtra apenas os casos relacionados à cidade de **Joinville**.

Os dados filtrados são salvos em um novo arquivo `.txt`.

---

## Tecnologias Utilizadas

- Python 3
- Biblioteca padrão `csv`
